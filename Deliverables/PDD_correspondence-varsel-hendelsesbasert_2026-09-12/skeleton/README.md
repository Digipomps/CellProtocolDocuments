# skeleton/ — ingen skeleton i denne oppgaven

Flatene er native (SwiftUI-menylinjeapp, AppKit-adminvindu, macOS' eget varslingssenter),
ikke CellConfiguration/skeleton-JSON rendret gjennom Porthole. Referansebildene i `images/`
er derfor HTML-mockups (se `images/README.md`), og det finnes ingen skeleton-JSON å legge her.
Mappen finnes for at `purpose_dev.py validate` skal se at artefaktet er *vurdert*, ikke glemt.
